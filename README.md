# 🎮 Tic-Tac-Toe

My first web development project which is a simple Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**.

## 🚀 Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Features

- Two-player gameplay
- X and O turn handling
- Automatic winner detection
- Draw detection
- Reset Game functionality
- Simple and responsive UI

## 🧠 Challenges I Faced

This was my first project using HTML, CSS, and JavaScript together, so I faced several difficulties while building it.

### 1. Handling Events

Initially, I struggled with JavaScript event handling and understanding how to properly detect which button was clicked and perform the required action.

### 2. Checking the Draw Condition

Implementing the draw condition was another challenge. I had to keep track of the number of moves and determine when all positions were filled without a winner.

### 3. Understanding `forEach()`

One of my funny learning moments was when I tried to use `forEach()` to access my winning combinations and expected it to return a value.

It doesn't. 😅

I learned that forEach() is mainly used to iterate over elements and does not return a new result like methods such as map() do. Understanding this helped me improve my knowledge of JavaScript array methods and return values.
